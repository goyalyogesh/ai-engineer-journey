## What I learned

- LCEL's `|` operator just means "feed left side's output into right side" —
  `prompt | llm | parser` is the whole concept; a retrieval chain is the same
  idea with a `{"context": ..., "question": ...}` dict running two things in
  parallel before the pipe continues.
- Document loaders normalize everything (PDF, web, CSV, etc.) into the same
  `Document` object shape (`.page_content` + `.metadata`) — same underlying
  extraction as `pypdf` on Day 15, just wrapped for interoperability.
- Chunk metadata survives splitting — each chunk still knows which page it came
  from, which matters for citing sources later in Project 1.
- Real proof RAG grounding works: asked the chain a question whose answer
  wasn't in the indexed subset (net sales figure, only page 1-20ish chunks were
  indexed) and it correctly said "the context does not contain the answer"
  instead of guessing — didn't hallucinate a number.
