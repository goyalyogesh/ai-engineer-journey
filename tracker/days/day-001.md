## What I learned

- LangChain's `ChatOpenAI` / `ChatGoogleGenerativeAI` / `ChatAnthropic` all implement the same chat-model interface — same `.invoke()`, same `SystemMessage`/`HumanMessage` role structure, regardless of provider. Swapping providers is a one-line change.
- Every LLM call follows the same shape: configure client → build role-tagged messages → `.invoke()` → read `.content` off the response object (not a plain string).
- `.env` + `load_dotenv()` keeps API keys out of source control — same discipline as pulling secrets from environment/config instead of hardcoding.
