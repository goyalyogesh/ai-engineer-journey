## What I learned

- `.env` values only reach `os.environ` if something calls `load_dotenv()` in *that specific process* — it's per-script, not automatic, not inherited from other files that happen to call it
- `instructor` exposes a different integration function per Google SDK: `from_genai` for the current `google-genai` package, `from_gemini` for the older, deprecated `google-generativeai` — installing the wrong SDK doesn't error, but calling the mismatched function does, since it's never registered as an attribute
- Instructor turns "call the LLM, get back a validated Pydantic object" into ~5 lines by passing `response_model=` directly to `.chat.completions.create()` — no manual `json.loads()`, no manual schema-matching, and Pydantic validators (like the email format check) run automatically on the model's output the same way they do on incoming API request bodies
- Debugging a real stack trace is mostly reading the *last* line of the traceback closely — all three bugs today had their fix stated almost verbatim in the final error message
