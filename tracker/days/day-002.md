## What I learned

- The same idiom keeps showing up: C#'s `foreach` + `if` + `.Add()` into a list collapses into one Python list comprehension line — same for LINQ `.GroupBy()` collapsing into a dict comprehension
- Python's `asyncio` is single-threaded, cooperative-multitasking-based — different execution model than .NET's thread-pool-backed `Task`, even though `async`/`await` syntax looks nearly identical on the surface
- `asyncio.gather()` runs concurrent work so total wait time is ~the slowest task, not the sum of all tasks — same payoff as `Task.WhenAll`
- Reinforced the `global` keyword issue from Day 3 (`03FastAPI.py`'s `id_counter`) — Python treats any name assigned to inside a function as local by default, unlike C# where a method can freely read/write a field with no special declaration
