## What I learned

- `pypdf` glues table numbers together with no space (`$ 307,003$ 294,866`)
  because it has no concept of table columns — just left-to-right character
  order. `pdfplumber` preserves real spacing because it tracks x/y position on
  the page.
- `pdfplumber.extract_tables()` gives back actual structured rows (Python
  lists), not just better-formatted text — the real reason to reach for it on
  financial statements specifically.
- `pdfplumber` was ~2.4x slower than `pypdf` on the same 111-page document —
  real tradeoff: speed vs. table fidelity, not a strictly-better/worse choice.
- Practical takeaway for Project 1: use `pypdf` for prose sections (Risk
  Factors, Business, MD&A), `pdfplumber` for financial statement sections —
  page-type-aware extraction, not one library for the whole filing.
- SEC 10-Ks are natively **HTML/XBRL**, not PDF — PDF is a rendering, not the
  authoritative format. Worth remembering before assuming "download the 10-K"
  means "download a PDF."
